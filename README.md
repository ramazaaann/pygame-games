# Pygame Mini Games

A small collection of mini games built with Python and Pygame, with scores saved to a database.

## Games Included

### Snake
Classic snake game — eat food to grow longer while avoiding the walls and your own tail.

### Racing Game
A fast-paced racing game — dodge oncoming obstacles and survive as long as you can without crashing.

## Requirements

- Python 3.x
- Pygame

Install Pygame with:

pip install pygame

## How to Run

Clone the repository:

git clone https://github.com/ramazans7/projects.git
cd projects

Then run either game:

python snake.py

python racing_game.py

## Controls

Snake: Arrow keys to move

Racing Game: Arrow keys or WASD to steer
